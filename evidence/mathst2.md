# Evidence map — Mathematics T2

| Learning claim | Mathematical basis / check |
|---|---|
| Characteristic equation | det(A−λI)=0; verify by direct determinant expansion |
| 2×2 trace/determinant shortcut | p(λ)=λ²−tr(A)λ+det(A); check roots by sum and product |
| Eigenspace | Solve (A−λI)v=0 with v≠0 |
| Distinct eigenvalues | Eigenvectors for distinct eigenvalues are linearly independent |
| Diagonalisation | A is diagonalisable iff it has n independent eigenvectors |
| Algebraic vs geometric multiplicity | GM=dim null(A−λI), and 1≤GM≤AM |
| Real symmetric matrices | Spectral theorem: real eigenvalues and orthogonal diagonalisation |
| Cayley–Hamilton | p_A(A)=0; checked exactly for A=[[2,1],[1,2]] |
| Inverse from Cayley–Hamilton | For invertible 2×2 A, A⁻¹=(tr(A)I−A)/det(A) |
