# Evidence map — Unit III, Design of Experiments, Topic 3B.5

- Topic: design-t5, Principles of Experimental Design.
- No official PYQ is claimed; mastery questions are original practice.
- Core principles: replication, randomisation and local control.
- Replication is at the independently assigned experimental-unit level; repeated readings on one unit are not automatically independent replications.
- Randomisation uses chance allocation, subject to the design restrictions, and protects against systematic allocation bias; it does not guarantee equal realised groups.
- Local control groups similar units using a nuisance factor; blocking can reduce residual variation and improve precision.
- CRD uses no explicit blocks; RBD controls one blocking factor; Latin square controls two orthogonal blocking directions.
- verify_design_t5.py checks unit counts, common layout sizes and conceptual contract; lesson_design_t5.py checks scene and mastery distributions.
